# 奋斗值计算器

Windows 桌面程序，登录 iTalent 后自动获取本月考勤，计算奋斗值与关键考勤指标。

## 当前默认计算规则

- 奋斗值 = 工作日单日加班小时 + 单休日加班小时 + 申请加班总小时数（非工作日） - 缺勤时长 - 请假时长
- 工作日单日加班小时 = 早上8点半之前+下午5点半之后
- 单休日加班小时 = 早上8点半之前+下午6点半之后（一小时吃饭时间不算） + 8小时（12:00~13:00午休时间不算）
- 申请加班总小时数 = 申请加班的实际加班时间相加
- 缺勤时长 = 向上半小时取整（例如缺勤1分钟 = 缺勤30分钟）（早上08:35:59之前打卡不算迟到）
- 请假时长 = 各种请假均计算请假时长（年假除外）
